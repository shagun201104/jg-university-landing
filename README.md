# JG University Landing Page

A modern responsive landing page redesign inspired by [jguni.in](https://jguni.in/), built with Next.js and Tailwind CSS.

## Tech Stack

- Next.js App Router
- Tailwind CSS
- Lucide React icons

## Sections

- Responsive navbar with mobile menu
- Hero section with campus imagery
- About section
- Programs/features section
- Campus and infrastructure highlights
- Animated partner strip
- Testimonials
- CTA and submission checklist
- Footer

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production Build

```bash
npm run build
npm start
```
